# Код города: команда МФТИ и Сколково

Кейс-чемпионат МГТС «Код города», направление «ИИ в бизнес-процессах». Дашборд для анализа ежемесячной обратной связи стажёров и наставников.

- `docs/index.html` — сайт команды (GitHub Pages).
- `docs/dashboard-prototype.html` — кликабельный макет дашборда на выдуманных данных.
- `prototype/` — прототип на Streamlit: приём ответов, сигналы, разбор комментариев. Запуск и ограничения описаны в `prototype/README.md`.

Все имена, оценки и комментарии в макете и прототипе выдуманы для демонстрации.
